Drone Mission Planner

Pre-flight feasibility calculator for autonomous drone delivery missions

Overview

A Python tool for planning drone delivery missions. Input destination coordinates, drone speed, battery capacity, and consumption rate -- it calculates distance, flight time, battery requirements, and determines if the mission is feasible before the drone leaves the ground. Results print to terminal and auto-save to a mission log file.

Try It Live

How It Works

1. Input destination as X, Y coordinates (meters from home base at origin)
2. Calculate straight-line distance using the Pythagorean theorem
3. Compute round-trip flight time from distance and speed
4. Calculate required battery from flight time and consumption rate
5. Compare against available battery capacity for go / no-go decision

The Math

Distance: d = sqrt(x² + y²)
Round Trip: 2d
Flight Time: t = 2d / speed
Required Battery: b = t * consumption_rate
Feasibility: available_battery >= required_battery

Example Output

Destination: (10000 x, 5500 y) Distance (m): 11412.71m Speed: 25 m/s Flight Time: 456.51s Battery Consumption: 25 mAh/s Required Battery: 11412.71 mAh Available Battery: 20000 mAh Mission Feasible: True Mission saved to mission_log.txt
