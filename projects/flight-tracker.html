Live Flight Tracker

Real-time aircraft tracking over any location on Earth

Overview

A Python CLI tool that tracks all flights currently flying over any searched location. Uses the OpenSky Network API for live ADS-B flight data and Nominatim/OpenStreetMap for geocoding. Results display in terminal and export to both CSV and TXT formats.

Try It Live

Search any location to see flights currently overhead, using the same APIs as the CLI tool.

Searching for flights...

Live data from the OpenSky Network. Coverage is strongest in Europe, North America, and parts of Asia.

How It Works

1. User enters a location (e.g. "London, United Kingdom")
2. Nominatim API converts location to bounding box coordinates
3. OpenSky Network API returns all aircraft in that airspace
4. Data is parsed: callsign, registration country, altitude (converted to feet/flight levels), speed (converted to knots)
5. Results print to terminal + save to CSV and TXT
